# Welcome to the HDFC Flutter Hackathon! 🚀

We’re excited to have you join us. Please complete the preparation below before the event so you can focus on the problem statement during the hackathon.

## Environment Setup

Install the latest stable Flutter SDK, preferably Flutter 3.47.0. Run `flutter doctor` and resolve any major issues for the platform you plan to use. Refer to the [Flutter installation guide](https://docs.flutter.dev/install/quick) if needed.

Make sure Android Studio or VS Code has the Flutter and Dart plugins installed and working.

## Sample App Preparation

Create a new Flutter project and run it on at least one Android or iOS device, emulator, or simulator.

Add two or three basic screens with simple navigation, such as Home → Details → Settings. Centered placeholder text on each screen is enough.

Check that you can debug the app from your IDE, including setting breakpoints and stepping through code. From a clean checkout, the app should run with:

```bash
flutter pub get
flutter run
```

## Repository Setup

Push your starter project to a public Git repository using the naming format `name_surname_hdfc_hackathon_2026`. For example, if your name is Sumit Chouhan, name the repository `sumit_chouhan_hdfc_hackathon_2026`.

Add a short `README.md` to your starter project with the steps to run the app, your Flutter SDK version, and the platform you tested. We’ll share a collaborator email address at the venue; please add it to your repository then so we can review your work.

Please also clone the hackathon repository shared with you. At this stage, only its README will be visible. The problem statement and additional resources will be made available as the hackathon progresses.

## What to Bring

Bring your laptop and charger. If you plan to test on a physical Android or iOS device, bring a working USB cable.

## Support

If you face any issues with the setup or sample app, please reach out before the event so we can help you get unblocked.

We’re looking forward to seeing what you build! 💡
